# 🏥 Hospital ERP System

병원 업무의 효율성을 높이기 위한 맞춤형 ERP 시스템 프로젝트입니다.

## 🚀 주요 기능
- **대시보드 (Dashboard):** 병원 운영 현황 및 주요 지표 시각화
- **예약 관리 (Appointment):** 환자 예약 등록, 수정 및 스케줄러 기능
- **환자 관리 (Patient Management):** 환자 정보 등록 및 조회
- **진료 기록 (Medical Records):** Encounter 기반 구조 및 SOAP 노트 형식의 진료 기록 작성

## 🛠️ 기술 스택
- **Frontend:** Next.js, TypeScript, Tailwind CSS
- **Backend:** Node.js (erp-api-server)
